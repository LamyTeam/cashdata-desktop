# 캐시데이터 데스크탑

[최신 Windows 설치 파일 다운로드](https://github.com/LamyTeam/cashdata-desktop/releases/latest)

Windows 64비트용 설치 파일은 Releases에서 제공합니다.

## 설치와 업데이트

1. 최신 릴리스의 `CashData-버전-x64.exe`를 내려받아 설치합니다.
2. 앱을 시작하면 새 버전을 자동으로 확인하고, 업데이트가 있으면 내려받아 설치한 뒤 다시 실행합니다. 앱은 실행 중에도 새 버전을 주기적으로 확인합니다.

수집·발행 작업이 진행 중이면 업데이트 설치가 보류됩니다.

이 저장소는 설치 파일 배포 전용입니다. 문의할 때는 비밀번호·API 키·개인정보를 제외하고 앱 버전과 증상을 알려 주세요.

## 라이선스

CashData의 공급사·저작권자는 Lamy Solution입니다. 설치·사용 전에 [소프트웨어 라이선스 계약서](LICENSE.md)를 확인하세요. 각 버전의 설치 안내에서도 해당 버전의 계약서를 확인할 수 있습니다.
